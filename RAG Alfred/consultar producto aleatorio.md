## FUNCIONALIDAD: CONSULTAR UN PRODUCTO ALEATORIO

### OBJETIVO

Permite acceder directamente a un producto seleccionado aleatoriamente entre los productos disponibles.

### REQUISITOS PREVIOS

* Ninguno.

### CÓMO CONSULTAR UN PRODUCTO ALEATORIO (PASO A PASO)

1. Entrar en la **Pantalla principal**.
2. Localizar la acción **Voy a tener suerte**.
3. Pulsar la acción.
4. El sistema selecciona un producto disponible de forma aleatoria.
5. Se muestra el producto seleccionado para su consulta.

### ELEMENTOS DE LA PANTALLA

* **Voy a tener suerte:** Solicita la selección aleatoria de un producto.
* **Producto:** Muestra los datos del producto seleccionado.

### CASOS ESPECIALES Y VARIACIONES

* Los productos que no deben estar disponibles para el usuario autenticado se excluyen según las reglas de disponibilidad de la aplicación.

### ERRORES Y SOLUCIONES

* **Error:** No se muestra un producto.

  * **Significado:** Puede no existir un producto disponible para seleccionar.
  * **Acción requerida:** Volver a la pantalla principal y consultar el catálogo o realizar una búsqueda.

### RESULTADO ESPERADO

Se muestra un producto disponible seleccionado aleatoriamente.
