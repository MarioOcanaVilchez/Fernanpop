## FUNCIONALIDAD: EDITAR UN MENSAJE

### OBJETIVO

Permite modificar un mensaje propio durante las primeras 24 horas desde su envío.

### REQUISITOS PREVIOS

* Estar autenticado.
* Tener un mensaje propio en un chat.
* El mensaje debe tener menos de 24 horas.
* El mensaje no debe haber sido eliminado.

### CÓMO EDITAR UN MENSAJE (PASO A PASO)

1. Abrir el chat.
2. Localizar un mensaje propio.
3. Abrir el menú de acciones del mensaje.
4. Pulsar **Editar**.
5. Se abre la pantalla **Editar mensaje**.
6. Revisar el **Mensaje anterior**.
7. Introducir el nuevo contenido.
8. Pulsar **Actualizar**.
9. El sistema guarda el nuevo contenido.
10. Se vuelve al chat.
11. El mensaje muestra el texto actualizado.

### ELEMENTOS DE LA PANTALLA

* **Mensaje anterior:** Muestra el contenido y fecha del mensaje que se va a editar.
* **Nuevo mensaje:** Campo donde se introduce el nuevo contenido.
* **Actualizar:** Guarda el contenido modificado.

### CASOS ESPECIALES Y VARIACIONES

* La acción **Editar** solo se muestra para mensajes propios con menos de 24 horas.
* Un mensaje eliminado no puede editarse.
* Los mensajes de otros usuarios no pueden editarse desde el chat.

### ERRORES Y SOLUCIONES

* **Error:** "Error al editar el mensaje"

  * **Significado:** No se pudo actualizar el mensaje.
  * **Acción requerida:** Volver al chat, comprobar que el mensaje sigue siendo editable y repetir la operación.

### RESULTADO ESPERADO

El mensaje propio queda actualizado con el nuevo contenido.
