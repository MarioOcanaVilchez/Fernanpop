## FUNCIONALIDAD: CONSULTAR MIS PRODUCTOS

### OBJETIVO

Permite consultar todos los productos publicados por el usuario y acceder a sus acciones de actualización o eliminación.

### REQUISITOS PREVIOS

* Estar autenticado.

### CÓMO CONSULTAR MIS PRODUCTOS (PASO A PASO)

1. Entrar en **Perfil**.
2. Pulsar **Productos**.
3. Se abre **Mis Productos**.
4. Revisar el listado de productos publicados.
5. Para modificar un producto, abrir el menú de tres puntos y pulsar **Actualizar**.
6. Para eliminarlo, abrir el menú y pulsar **Eliminar**.

### ELEMENTOS DE LA PANTALLA

* **Lista de productos:** Muestra los productos publicados por el usuario.
* **Imagen:** Imagen del producto o imagen predeterminada.
* **Título:** Nombre del producto.
* **Descripción:** Descripción publicada.
* **Precio:** Precio del producto.
* **Menú de tres puntos:** Acciones de cada producto.
* **Actualizar:** Edita el producto.
* **Eliminar:** Elimina el producto.

### CASOS ESPECIALES Y VARIACIONES

* Si el usuario no tiene productos, se muestra **No ha puesto a la venta ningún producto**.
* El menú de cada producto contiene las acciones **Actualizar** y **Eliminar**.

### ERRORES Y SOLUCIONES

* **Error:** "Error al actualizar el producto"

  * **Significado:** No se pudieron guardar los cambios.
  * **Acción requerida:** Comprobar la conexión y repetir la actualización.
* **Error:** "Error al borrar el producto"

  * **Significado:** No se pudo eliminar el producto.
  * **Acción requerida:** Comprobar la conexión y repetir la eliminación.

### RESULTADO ESPERADO

El usuario puede consultar y administrar sus productos publicados.
