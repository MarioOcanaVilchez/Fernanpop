## FUNCIONALIDAD: VACIAR UN CHAT

### OBJETIVO

Permite eliminar los mensajes de un chat para el usuario actual.

### REQUISITOS PREVIOS

* Estar autenticado.
* Tener un chat existente.

### CÓMO VACIAR UN CHAT (PASO A PASO)

1. Abrir **Chats**.
2. Localizar la conversación.
3. Abrir el menú de tres puntos del chat.
4. Pulsar **Vaciar chat**.
5. El sistema elimina los mensajes del chat para el usuario actual.
6. El usuario vuelve a la pantalla correspondiente.
7. Al volver a abrir la conversación, el chat aparece sin los mensajes eliminados para ese usuario.

### ELEMENTOS DE LA PANTALLA

* **Vaciar chat:** Elimina los mensajes del chat para el usuario actual.

### CASOS ESPECIALES Y VARIACIONES

* Vaciar el chat es diferente de eliminar un mensaje individual.
* La acción se ejecuta desde el menú del chat.

### ERRORES Y SOLUCIONES

* **Error:** "Error al vaciar el chat"

  * **Significado:** No se pudo completar la eliminación de mensajes.
  * **Acción requerida:** Comprobar la conexión y volver a intentarlo.

### RESULTADO ESPERADO

El chat queda vacío para el usuario actual.
