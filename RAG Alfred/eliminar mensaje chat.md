## FUNCIONALIDAD: ELIMINAR MENSAJES

### OBJETIVO

Permite eliminar mensajes de la vista del usuario o eliminar su contenido para todos cuando se trata de un mensaje propio.

### REQUISITOS PREVIOS

* Estar autenticado.
* Tener un chat con mensajes.

### CÓMO ELIMINAR UN MENSAJE (PASO A PASO)

1. Abrir **Chats**.
2. Entrar en la conversación.
3. Localizar el mensaje.
4. Abrir el menú de acciones del mensaje.
5. Para eliminarlo solo de la vista personal, pulsar **Eliminar para mi** en un mensaje propio o **Eliminar** en mensajes de otros usuarios/administración.
6. Para eliminar el contenido para todos, en un mensaje propio pulsar **Eliminar para todos**.
7. El sistema procesa la eliminación.
8. El chat se vuelve a cargar.
9. El mensaje deja de estar disponible según el tipo de eliminación seleccionado.

### ELEMENTOS DE LA PANTALLA

* **Eliminar para mi:** Elimina el mensaje para el usuario actual.
* **Eliminar para todos:** Elimina el contenido del mensaje propio para todos.
* **Eliminar:** Elimina el mensaje de la vista del usuario en los casos disponibles.

### CASOS ESPECIALES Y VARIACIONES

* **Eliminar para todos** solo está disponible para mensajes propios que todavía no estén eliminados.
* Un mensaje propio puede mostrar simultáneamente **Eliminar para todos** y **Eliminar para mi**.
* Los mensajes de otros usuarios no ofrecen **Eliminar para todos**.
* Los mensajes de administración pueden eliminarse de la vista del usuario.

### ERRORES Y SOLUCIONES

* **Error:** "Error al eliminar el mensaje"

  * **Significado:** No se pudo procesar la eliminación.
  * **Acción requerida:** Comprobar la conexión y repetir la operación.

### RESULTADO ESPERADO

El mensaje queda eliminado conforme a la opción seleccionada.
