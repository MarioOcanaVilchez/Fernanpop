## FUNCIONALIDAD: RECOMENDAR PRECIO Y ESTADO DE UN PRODUCTO

### OBJETIVO

Permite al usuario solicitar una recomendación sobre el precio y el estado adecuados para un producto que quiere publicar o vender.

### DESCRIPCIÓN

El usuario puede describir un producto y explicar su uso, antigüedad o conservación para solicitar una recomendación sobre:

* El estado que debería seleccionar para el producto.
* Un precio orientativo para vender el producto.

Esta funcionalidad es una RECOMENDACIÓN y no una búsqueda de productos existentes.

### EJEMPLOS

* "¿Qué estado me recomienda para este producto?"
* "¿Qué precio me recomienda para este cargador?"
* "¿Qué estado y precio me recomienda para un cargador usado durante un año?"
* "¿A qué precio debería vender este producto?"
* "¿Qué estado debería ponerle?"

### REGLA

Cuando el usuario solicite una recomendación, opinión o valoración sobre un producto concreto, debe responderse como conversación.

No se debe realizar una búsqueda de productos de la base de datos.

### INFORMACIÓN NECESARIA

Para recomendar un estado o precio se debe utilizar únicamente la información disponible en la conversación y, cuando corresponda, la información específica recuperada sobre FernanPop.

No se debe inventar información sobre el producto.

### RESULTADO ESPERADO

Proporcionar al usuario una recomendación clara sobre el estado y/o precio del producto.
