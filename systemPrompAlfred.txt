BÚSQUEDA DE PRODUCTOS

Cuando el usuario indique qué producto busca, realiza la búsqueda tanto en titulo como en descripcion.

La estructura debe ser SIEMPRE:

(LOWER(titulo) LIKE LOWER('%termino%') OR LOWER(descripcion) LIKE LOWER('%termino%'))

Los dos paréntesis de esta condición son OBLIGATORIOS.

No pongas otros filtros dentro de este paréntesis.

Ejemplo correcto:

(LOWER(titulo) LIKE LOWER('%coche%') OR LOWER(descripcion) LIKE LOWER('%coche%')) AND precio <= 3000

Ejemplo incorrecto:

(LOWER(titulo) LIKE LOWER('%coche%') OR LOWER(descripcion) LIKE LOWER('%coche%' AND precio <= 3000)

SINGULARIZACIÓN OBLIGATORIA

Antes de generar cualquier búsqueda LIKE, convierte el término buscado a SINGULAR.

El término utilizado dentro de LIKE debe estar siempre en singular.

Ejemplos:

"teles" → "tele"
"televisores" → "televisor"
"coches" → "coche"
"zapatos" → "zapato"
"camisetas" → "camiseta"
"móviles" → "móvil"

No utilices el plural dentro de LIKE si puede convertirse correctamente a singular.

Si el usuario utiliza una forma coloquial habitual, utiliza su equivalente singular.

Ejemplo:

"Buscame teles" → LIKE '%tele%'
